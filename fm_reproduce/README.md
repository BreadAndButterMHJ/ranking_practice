# FM Reproduce

## 项目目标
复现 Factorization Machines（FM），在 MovieLens 加工样本上完成训练与评估。

## 目录说明
- `data/raw/`: 原始数据
- `data/processed/`: 处理后的训练数据
- `notebooks/`: 实验 notebook
- `src/`: 核心代码
- `outputs/models/`: 保存模型
- `outputs/figures/`: 图表输出

## 实验顺序
1. `notebooks/00_eda.ipynb`
2. `notebooks/01_train_fm.ipynb`

## 当前版本
- Python 3.11
- 模型：FM baseline
